# gostinator

генератор чертежей из 3D моделей
`.SLDPRT` -> `.SLDDRW` и `.pdf`

## Требования
 - установленный SolidWorks 2017
 - os windows

## Запуск

Распакуй архив сборки из релизов [Releases](https://github.com/Atridis/gostinator/releases) и запусти `gostinator-ui.exe`, далее укажи папку с файлами `.SLDPRT` и папку в которую нужно положить сгенерированные файлы
